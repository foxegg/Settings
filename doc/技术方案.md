# 桌面投影辅助批改系统技术方案

本文是已确认需求的技术方案，供 Android 一期实现与后续投影扩展使用。怎么编译、配置密钥和演示模式，见 [开发说明.md](开发说明.md)。

## 1. 方案要点

这是辅助批改，不是自动改完。每张试卷由用户点「批改」后，才请求一次大模型并返回结果。前期在手机摄像头画面上叠加辅助批改图层；后续再由投影仪把同一套图层打到纸面实际位置。用户对照结果动手写到纸上。系统本身不做对错或给分判断。

| 项目 | 约定 |
| --- | --- |
| 用途 | 辅助批改，结果仍由用户动手写上 |
| 触发 | 每张试卷由用户确定后，才请求一次大模型 |
| 采集 | 手机摄像头朝下拍摄 |
| 一期输出 | 在摄像头画面上叠加辅助批改图层 |
| 后续输出 | 投影仪只打辅助图层，对准纸面实际位置 |
| 对准 | 挪动可实时跟随；轻微变形用网格对准；严重褶皱或卷曲时最好先摊平 |

不要把带原卷内容的完整生成图叠到画面或投到纸上，只使用透明背景的批改图层（对钩、叉、圈画、旁批、分数提示）。

## 2. 使用方式

1. 放好试卷。摄像头持续看桌面，跟踪纸张当前位置，此时不请求大模型。
2. 点「批改」。系统拍下当前画面（如已接投影，先关闭投影或切到黑帧），请求一次大模型并等待返回。
3. 对照结果动手写。辅助标记出现在纸面对应位置；纸被挪动或轻微变形时，图层跟着对准。
4. 换下一张后再点一次「批改」，才会发起下一次模型请求。

## 3. 投影与纸面实时对准

| 纸面变化 | 能否实时对准 | 做法 |
| --- | --- | --- |
| 平移、转动、稍微斜放 | 可以 | 每帧跟踪纸面，更新变换 |
| 轻微起皱、边角微翘 | 多数时候可以 | 不只靠四个角，用纸面上多个点做网格对准 |
| 摺痕很深、严重卷曲或揉皱 | 容易偏 | 纸不再是平面，最好先摊平再改 |
| 大模型批改 | 不实时 | 只在用户点「批改」时请求一次，与对准分开 |

书写时手挡住部分画面，应靠仍看得见的边角和纹理继续跟踪，避免一下就丢。跟踪在点「批改」之前就可以一直开着。

## 4. 硬件清单与安装（后续接投影时）

一期只需手机，不需要投影仪和电脑。后续完整系统建议：

| 设备 | 作用 | 选型要点 |
| --- | --- | --- |
| 刚性俯拍支架 | 把手机和投影仪固定在桌面上空 | 承重足够、尽量少晃，可用桌夹臂、灯臂或铝型材架 |
| 手机 | 朝下拍摄、跟踪纸面，并发送「批改」请求 | 后置摄像头，1080p 或以上；固定后锁住对焦和曝光 |
| 投影仪 | 只打辅助批改图层 | 支持俯视或吊装翻转，HDMI 输入，优先原生 1080p |
| 电脑 | 跟踪对准、生成图层、请求大模型、输出到投影 | 笔记本或迷你主机，HDMI 接投影仪，与手机同一局域网 |
| 线材与标记 | 连接设备，辅助跟踪 | HDMI 线、供电；可选打印桌面四角标记 |

投影画面不必刚好等于一张 A4。只要覆盖整张试卷并略留余量，其余区域保持黑屏即可。支架高度以手机能完整拍到试卷、手下有书写空间为准，常见大约四十到七十厘米，以实机画面为准。

投射比等于镜头到纸面的距离除以画面宽度。近距离只覆盖一张卷时，通常是常规投射比；不要按客厅投百吋去选超短焦机，那个高度往往会投得过大。亮度请看 ANSI、ISO 或 CVIA 等规范标注，不要只看「光源流明」。关掉投影仪自带的梯形校正，改用软件标定对准。设备相对位置一旦固定，标定做一次即可；被碰动后要重标。

## 5. 技术实现

系统里同时跑两条链路：

- **对准链路（持续运行）**：相机取流，检测四角和纸面特征点，估计位置与轻度变形，把已有图层变换到画面（一期）或投影仪输出（后续），不请求大模型。
- **批改链路（点一下才走）**：先避免投影污染画面，拍当前帧，把纠正后的试卷图和评分标准发给多模态大模型，按其返回的位置和内容画出辅助图层。
- **标定（接投影后，安装时做一次）**：向工作区投出棋盘格或点阵，用相机拍下，求出相机与投影仪在桌面平面上的变换并保存。

大模型不要直接生成带原卷的完整图片。让它返回结构化标注，坐标用纸面归一化位置（左上为原点，宽高各为 1）。例如：

```json
{
  "marks": [
    {"type": "check", "x": 0.72, "y": 0.18},
    {"type": "cross", "x": 0.72, "y": 0.31},
    {"type": "text", "x": 0.80, "y": 0.45, "text": "要点不完整"}
  ]
}
```

评分标准或参考答案由用户在应用内提供或从本地文件载入，不要把密钥写进仓库。

一期手机应用默认把纠正后的这一帧发给阿里云百炼（Model Studio）OpenAI 兼容接口的 `qwen3-vl-plus`。地址、模型名和密钥都在本机配置；本机能访问 Google API 时，可以改成 Gemini 3.1 Pro（`gemini-3.1-pro-preview`）。模型只在用户点「批改」时请求一次，不参与跟踪、对准或投影。没有密钥时用演示模式叠本地示例标记，用来检查对准。

## 6. 分期

1. **一期：手机叠加验证。** Android 应用：实时跟踪纸面（平移、转动、轻斜，以及用多于四角的网格应对轻微褶皱或翘角），点「批改」后请求一次大模型，把辅助图层叠在摄像头画面对应位置上。可提供无密钥时的演示模式（用本地示例标注验证对准）。严重褶皱或卷曲时提示先摊平。不实现投影仪输出。
2. **二期：投影并实时跟随。** 完成相机与投影仪标定，把同一套辅助图层投到纸面；挪动时复用一期的跟踪与网格对准。
3. **三期：换卷体验与留存。** 缩短等待，换卷再点即可继续，并可按需保留当次辅助结果。

一期的手机预览里已经包含多点网格对准。原稿把网格写在二期；按已确认的范围，轻微褶皱要在手机阶段就能跟着走，二期投影复用这套对准，而不是到投影时才开始做网格。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 误以为会一直自动批改 | 只有用户点「批改」才请求一次大模型 |
| 把带原卷的整张生成图直接叠加或投影 | 只生成并显示透明辅助图层 |
| 书写时纸被挪动或轻微变形 | 实时跟踪；轻微变形用多点网格，而不是只靠四个角 |
| 大模型辅助结果不准 | 本方案是辅助，最终仍由用户写到纸上 |
| 摺痕很深、严重卷曲或揉皱 | 平面对准会失效，提示先把纸摊平再改 |
| 学生作业图像隐私 | 仅在用户确定后才把当次图像送给大模型，并约定是否留存 |
